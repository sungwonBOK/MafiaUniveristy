# 맵 디자인 및 스킬 연출 구현 계획 (To-Do)

본 문서는 MafiaUniversity의 다음 개발 단계인 **물리 엔진 기반의 맵 타일 구성**과 **각 직업 고유의 스킬(능력) 애니메이션 및 UI 연출**을 상세하게 정의한 기획서입니다. 다음 작업을 이어받는 AI는 이 문서를 가이드라인 삼아 개발을 시작하십시오.

---

## 🗺️ 1. 실제 학교 맵 타일 연동 (Tiled)

현재 `GameScene.ts`는 물리 타일맵 파일이 없어 임시로 푸른색 격자무늬 프로토타입 맵을 렌더링하고 있습니다. 이를 해결하기 위해 다음 작업이 필요합니다:

### 1-1. Tiled(.json, .png) 맵 데이터 제작 및 배치
1. **타일셋 이미지 확보**: `packages/client/public/maps/` 디렉토리에 학교 컨셉과 어울리는 `tiles_prototype.png` 타일셋 리소스를 추가해야 합니다.
2. **에디터 맵 제작**: [Tiled](https://www.mapeditor.org/)와 같은 맵 에디터를 이용해 방, 복도, 벽 등의 지형을 구성합니다.
3. **충돌(Collision) 레이어 설정**: 맵 JSON(예: `map_prototype.json`)에서 벽이나 장애물 타일에 `collides: true` 속성을 명시적으로 부여합니다.

### 1-2. 클라이언트 엔진 연동 (`GameScene.ts` & `PreloadScene.ts`)
1. **로딩 복원**: `PreloadScene.ts`에 주석 처리되어 있는 `this.load.image`와 `this.load.tilemapTiledJSON` 라인을 활성화합니다.
2. **레지스트리 활성화**: `SchoolMapRegistry.ts` 파일에서 학교별 타일맵 Key 값과 틴트(Tint) 값 등이 올바르게 맵핑되도록 설정합니다.
3. **충돌 처리 적용**: `GameScene` 의 `createMap()` 함수에 작성되어 있는 물리 충돌 코드(`collider`)가 정상 작동하여 벽을 통과할 수 없는지 확인합니다.

## ✨ 2. 직업 스킬(능력) 이펙트 및 UI 구현

현재 서버 로직(`GameService.ts`)상으로 킬, 역할 분배, 투표 추방 처리는 완성되어 있으나, 프론트엔드 단에서의 화려한 **시각적 애니메이션**과 **추가 직업 스킬 발동 UI**가 부족합니다.

### 2-1. 공통 십자선(Targeting) UI 추가
- **마우스 커서 타겟팅**: 스킬(스페이스바)를 그냥 방출하는 것이 아니라, 마우스 커서 주변이나 호버하는 유저에게 **십자선(Crosshair)** 이펙트를 띄워주는 방식으로 개선해야 합니다.
- 스킬 발동 시 어떤 유저에게(타겟팅) 능력이 들어가는지에 대한 시각적 피드백(빨간색 조준점, 초록색 방패 마크 등)을 화면상에 추가합니다.

### 2-2. 마피아 (Mafia) — '킬(Kill)' 연출
- **킬 이펙트**: 마피아가 목표 대상을 킬했을 때 단순히 `isAlive = false` 처리로 끝나는 것이 아니라, 화면에서 칼로 베이는 이미지 효과나 붉은 데미지 파티클 애니메이션을 1초 정도 노출시킵니다.
- **사체 남기기**: 사망한 유저가 그대로 멈춰서 반투명해지는 현재 코드에서 한 단계 더 나아가, 바닥에 영구히 남아있는 '엎드린 시체 스프라이트(Dead Body)' 객체로 대체 생성합니다.

### 2-3. 의사 (Doctor) — '보호(Heal/Protect)' 연출
- **스킬 로직 연동**: 인게임 화면 좌측 상단 또는 본인 캐릭터 근처에 쿨다운 UI를 띄워주고, 치료/보호 스킬 시전 시 다른 사람 캐릭터에 **초록색 십자가 힐링 파티클이나 반투명한 푸른색 보호막 원**을 씌우도록 클라이언트 기능을 개발합니다.
- 서버단(`GameHandler.ts`의 `USE_ABILITY` 내)에 'doctor' 일 경우의 무적기/보호막 판정을 덧붙여 킬이 들어왔을 때 상쇄하는 로직과 맞물려야 합니다.

### 2-4. 탐정 (Detective) — '스캔(조사)' 연출
- **조사 애니메이션**: 탐정이 스킬을 사용해 특정 상대를 눌렀을 때, 카메라 플래시나 **돋보기 이펙트**가 타겟 위에 반짝이게 렌더링합니다.
- 조사가 완료되면 (서버가 응답을 보내면) UIScene 우측 하단이나 게임 내 모달로 대상의 역할이 무엇인지(마피아인지 아닌지) 텍스트를 잠깐 띄워주고 사라지게 합니다.
